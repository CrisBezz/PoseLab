# PoseLab

**Import a 3D character. Become its skeleton.**

PoseLab is an iPad/iPhone-first character posing tool built around ARKit body tracking.

## V0.1 — Live Skeleton
- rear-camera ARKit body tracking
- live body-joint visualization
- tracking state + joint count
- freeze/resume pose
- ARKit-independent PoseSnapshot boundary ready for retargeting

## Next milestone
Replace the debug joint spheres with a known rigged humanoid and add the first explicit ARKit → character joint map.
