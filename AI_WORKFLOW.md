# PoseLab AI Development Workflow

Before modifying code:
1. Read AI_HANDOFF.md.
2. Read the latest DEV_HISTORY.md entry.
3. Read TEST_CHECKLIST.md.
4. Inspect current source.

After each meaningful build:
1. Update DEV_HISTORY.md.
2. Update AI_HANDOFF.md.
3. Update TEST_CHECKLIST.md.
4. Keep commits small and descriptive.

Protected principles:
- iPad-first.
- Performer is the primary posing interface.
- Preserve target character proportions and bone lengths.
- Keep tracking, pose normalization, retargeting, rendering and export modular.
- Keep auto-rigging separate from capture/retargeting.
